# Projeto de Computação Gráfica – POV-Ray

## Sobre o projeto

Projeto acadêmico desenvolvido na disciplina de Computação Gráfica utilizando o **POV-Ray (Persistence of Vision Raytracer)**, ferramenta de renderização tridimensional que permite criar cenas por meio de instruções textuais.

O projeto explora a construção de objetos geométricos, composição de cenas e aplicação de técnicas de modelagem e renderização 3D.

## Linguagem e ferramenta

- **POV-Ray:** software utilizado para modelagem e renderização de cenas tridimensionais.
- **SDL (Scene Description Language):** linguagem de descrição de cenas utilizada pelo POV-Ray para definir objetos, materiais, iluminação, câmeras e demais elementos.

## Desenvolvimento da cena

A construção das cenas foi realizada por meio de código, utilizando elementos como:

- **Objetos geométricos:** criação de formas primitivas, como esferas, caixas, cilindros e outros sólidos.
- **Transformações geométricas:** posicionamento, rotação e redimensionamento dos objetos.
- **Materiais e texturas:** definição de cores, transparência, reflexão e propriedades das superfícies.
- **Iluminação:** posicionamento de fontes de luz para destacar os objetos e produzir efeitos de sombra.
- **Câmera:** configuração do ponto de vista e enquadramento da cena.
- **Renderização:** geração das imagens finais a partir das definições da cena.

## Operações booleanas (CSG)

Também foram exploradas operações de Geometria Sólida Construtiva (*Constructive Solid Geometry – CSG*), utilizadas para combinar ou modificar sólidos geométricos.

As principais operações trabalhadas foram:

- **União (Union):** combina dois ou mais objetos, formando uma única estrutura geométrica.
- **Diferença (Difference):** subtrai a geometria de um objeto de outro, criando recortes e cavidades.

Essas operações permitem construir formas mais complexas a partir de sólidos geométricos simples.

## O que aprendi

- Utilização da linguagem SDL do POV-Ray.
- Construção e composição de cenas tridimensionais por código.
- Manipulação de objetos e transformações geométricas.
- Aplicação de materiais, texturas e iluminação.
- Configuração de câmeras e renderização.
- Modelagem utilizando operações booleanas de união e diferença.
- Fundamentos de Computação Gráfica e representação de objetos 3D.
